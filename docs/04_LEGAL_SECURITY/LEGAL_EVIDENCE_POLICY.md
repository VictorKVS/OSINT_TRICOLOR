# L-001 Правовой и доказательственный контур
**Статус:** проект для юридической экспертизы. Не юридическое заключение.

## Объекты
Произведения / программы / вещание / товарные знаки / оборудование / домены / публичные судебные акты. Для каждого объекта установить правообладателя, объем и срок прав, территорию, лицензию, исключения, способ предполагаемого использования и источник права.

## Матрица «объект → основание → проверка»
| Объект | Проверить | Пример группы норм |
|---|---|---|
| Товарный знак | свидетельство, классы МКТУ, территорию, правомерное использование | ГК РФ ч. IV, ст. 1484, 1515 |
| Произведение | цепочку прав, разрешённое использование | ГК РФ ч. IV, ст. 1252, 1301 |
| Смежные права | наличие права на конкретное вещание/контент | ГК РФ ч. IV, нормы о смежных правах |
| Блокировка распространения | соблюдение установленной процедуры | 149-ФЗ, ст. 15.2, при применимости |
| Обработка ПД | основание, цель, объем, сроки, безопасность | 152-ФЗ |
Применимость и актуальные редакции требуют отдельной проверки перед внедрением.

## Evidence chain
Приём сигнала → фиксация доступного материала → UTC-время, URL и collector ID → криптохэш SHA-256 оригинала → защищённое хранение → журнал каждого обращения → экспертная проверка → управляемый экспорт. Скриншот один сам по себе не доказывает обстоятельства; способ фиксации согласовывается с юристом.

## Приоритеты безопасности
Запрет самостоятельного «доказательства виновности» моделью; разрешённые источники по allowlist; исключить активные вмешательства; короткие сроки хранения по категории и решению владельца; редактирование ПД в отчётах; защита от prompt injection из собираемых страниц; обязательная оценка доверия к источнику.

## Ручные процедуры
Претензии, обращения, взаимодействие с правоохранителями и иные юридические действия — только после уполномоченного согласования.
