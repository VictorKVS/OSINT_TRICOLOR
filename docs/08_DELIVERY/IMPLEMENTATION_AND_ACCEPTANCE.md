# I-001 План производства и критерии допуска
## Отделяем бумажную стадию от реализации
Предварительный макет agent.py НЕ развивать до G0–G7 review. Можно выполнять только безопасные учебные лабораторные эксперименты и тесты без доступа к живым данным.

## Work packages
WP1 документарный аудит G0–G4; WP2 пилотный corpus synthetic/authorized; WP3 sizing and architecture decision; WP4 API/DB and access design; WP5 shared OSINT integration; WP6 TRICOLOR profile; WP7 ALINA and SecGraph; WP8 QA + security + privacy; WP9 pilot; WP10 operation and upstream promotion.

## DoD каждой функции
Указано требование FR/NFR → проектное решение ADR → тест-кейс → код с review → наблюдаемость → безопасный отказ → эксплуатационный runbook → отчёт о тестировании.

## Пилот
По заранее утверждённым примерам: intake provenance, дедуп, работа лицензий и false positive, защита ПД, evidence integrity, контроль human review, доступность и восстановление. Сравнить с базовой ручной работой.

## Эксплуатация
Паспорт версии, инструкции пользователя/администратора, резервное копирование, реагирование на инцидент, журнал изменений, реестр угроз и недостатков, регламент актуализации источников и законодательства.

## Upstream
Каждая универсальная находка получает ID, обобщённую реализацию и тесты, PR к OSINT_deepseek, ревью совместимости и security, затем обновление отраслевого профиля.
