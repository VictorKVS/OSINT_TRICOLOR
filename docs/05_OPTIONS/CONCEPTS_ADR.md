# A-001 Концепции реализации и альтернативы
Решение не принято. Оценки являются предпроектными.

| Критерий | А. Расширение общего OSINT | B. Автономный отраслевой сервис | C. Гибридный профиль FATHER |
|---|---|---|---|
| Повторное использование | высокое | низкое | высокое |
| Уникальная логика СМИ | через настройки | отдельный код | плагины и правила |
| Скорость MVP | средняя | высокая | средняя |
| Технический долг | низкий при дисциплине | высокий из-за копирования | низкий при API-контрактах |
| Эксплуатация | централизованная | дублируется | централизованная |
| Интеграция ALINA/SecGraph | возможна | отдельно | стандартные интерфейсы |

**Предварительный выбор: C**, поскольку соответствует FATHER: единое шасси — разные надстройки — двустороннее развитие. Утвердить только после проверок совместимости и TCO.

## Границы компонентов
Core OSINT: источники, provenance, audit, dedup, риск-интерфейсы, graph API. Profile TRICOLOR: rights registry, отраслевые правила, case templates. ALINA: вспомогательные выводы с цитатами и uncertainty. SecGraph: граф взаимосвязей. Human decision: юридическая оценка и действия.

## ADR-001
Decision proposed: configuration-driven profile rather than fork. Consequences: adapter interfaces, shared contract tests, upstream enhancement lifecycle; explicit contract versions.
